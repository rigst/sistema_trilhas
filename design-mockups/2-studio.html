Fundamentos da linguagem

Variáveis, tipos e repetição — o alfabeto antes das palavras.

Gerando o material deste nível…
✓ ConceitosExemplos & códigoExercíciosBibliografia

Uma variável é um nome que aponta para um valor na memória. Em Python o tipo é inferido na atribuição — você escreve menos e explora dados mais rápido.

i
Conceito

Atribuição liga um nome a um objeto. x = 42 cria um inteiro e faz x apontar para ele — não copia para uma “caixa”.

1Tipos primitivos

Os quatro que você usará o tempo todo: int, float, str e bool.

tipos.py
# tipo inferido na atribuição
idade = 31              # int
altura = 1.78          # float
nome = "Ada Lovelace"   # str
ativo = True            # bool

print(type(idade), type(nome))
✓
Dica de prática

Rode type(x) no console quando uma conta der errado — quase todo bug de iniciante é um str onde se esperava int.

2Repetição com for

Some os quadrados de 1 a 5:

loop.py
total = 0
for n in range(1, 6):
    total += n * n
print(total)  # 55
!
Atenção

range(1, 6) vai até 5 — o limite superior é exclusivo. É a pegadinha nº 1.

✎ Exercício · feedback imediato
Se trocarmos range(1, 6) por range(1, 4), o que print(total) imprime?
✔ Correto! 1 + 4 + 9 = 14. Você domina o limite exclusivo do range.
✘ Quase. range(1, 4) percorre 1, 2, 3 — some os quadrados desses três.
