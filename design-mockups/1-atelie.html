Uma variável é um nome que aponta para um valor guardado na memória. Em Python você não declara o tipo — ele é inferido no momento da atribuição, o que torna a linguagem rápida de escrever e ótima para explorar dados.

Conceito

Atribuição é ligação de nome a objeto. x = 42 não copia 42 para uma caixa; cria um inteiro e faz x apontar para ele.

Subtópico 1Tipos primitivos

Os quatro tipos que você usará o tempo todo: int, float, str e bool. Repare como o mesmo nome pode passar a apontar para tipos diferentes:

tipos.py
# o tipo é inferido na atribuição
idade = 31              # int
altura = 1.78          # float
nome = "Ada Lovelace"   # str
ativo = True            # bool

print(type(idade), type(nome))
# <class 'int'> <class 'str'>
Dica de prática

Use type(x) no console sempre que uma conta der errado — quase todo bug de iniciante é um str onde você esperava int.

Subtópico 2Repetição com for

Laços percorrem sequências. Some os quadrados de 1 a 5:

loop.py
total = 0
for n in range(1, 6):
    total += n * n
print(total)  # 55
Atenção

range(1, 6) vai de 1 a 5 — o limite superior é exclusivo. É a pegadinha nº 1 de quem começa.

Qual valor print(total) imprime no laço acima se trocarmos range(1, 6) por range(1, 4)?

✔ Correto. 1² + 2² + 3² = 1 + 4 + 9 = 14. Você entendeu o limite exclusivo do range.
